# libs/

This folder holds the **third-party dependency jars** needed to compile the mod. They are not
included in this repository and must not be committed or redistributed.

Copy the following jars from your modpack's `mods/` folder (match the versions in
[DEVELOPMENT.md](../DEVELOPMENT.md#1-development-environment)):

- Iron's Spells 'n Spellbooks, irons_lib, GeckoLib, Player Animation Lib, Curios
- FTB Quests, FTB Library, FTB Teams
- Architectury API

See the "Local dependency jars" section in DEVELOPMENT.md for the Gradle notation.
